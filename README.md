# Яндекс Картинки: анализ поисковых запросов

Тестовое задание на позицию продуктового аналитика.

## Задача
Проверить гипотезу, что интересы пользователей поиска по картинкам
на мобильных (touch) и десктопных (desktop) устройствах отличаются.

## Данные
- `data.tsv` — семпл запросов к Яндекс Картинкам за 31.08–21.09.2021
  (1 114 365 строк): query, timestamp, platform
- `dataset_with_topics.csv` — данные с размеченными тематиками (26 категорий)

## Ноутбук
`test tregulov.ipynb` — анализ с SQL-запросами (pandasql), тематической
разметкой (BERTopic + эмбеддинги) и визуализацией:
диапазон дат, запросы с «ютуб», топ-10 по платформам, дневной трафик
(по часам, будни/выходные), контрастные тематики.

## Ключевые выводы
- Гипотеза подтверждена: интересы на платформах заметно отличаются.
- **Поздравления** — главный контраст для touch: 20.1% против 7.5% на desktop
  (личные/социальные сценарии: поздравить в мессенджере «здесь и сейчас»).
- **Учёба** (таблицы, алфавиты, ГДЗ) и **Календарь** контрастны для desktop —
  учебные и рабочие сценарии; **Обои** — устройство-специфичный запрос (Δ −2.8 п.п.).
- Мода/маникюр, кулинария, здоровье, спорт — «личный» досуг на мобильных.
- Дневной трафик: desktop — «рабочий» профиль (пик 10–16 UTC), touch — бимодальный
  (утро 6–7 UTC и вечер 17–18 UTC: дорога и досуг); ночью 75–77% трафика — touch.
- В выходные активность сдвигается позже и распределяется ровнее.
